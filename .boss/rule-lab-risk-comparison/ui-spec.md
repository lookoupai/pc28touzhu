# 风控比较组UI增量

在现有/rule-lab批次结果区加入“比较风控方案”，仅本人backtest+round独立批次显示。点击先GET preview，展示五候选实际变化/不可用原因、将新建版本数、全服务剩余保存容量及100运行限制；说明原批次保留、全新baseline、默认暂停。request_id由浏览器一次生成，未知结果保留同token可安全重试；新意图才换token。

页面新增比较组列表和详情：状态、每子方案进度、队列等待原因、共同截止、实际覆盖、可比状态。启动按钮为“启动比较队列”，暂停停止新准入但保留已冻结结算。child由组管理，不显示单独启动/修改；可打开其原有批次与逐期/轮详情。
