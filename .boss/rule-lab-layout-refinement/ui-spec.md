# 结果优先布局

- 调整级别：中等结构重组。原列表把运行说明、样本解释、月度序列和操作按钮放在同一层，导致单元格过长；现在用一个主要结果区与逐层展开的信息阅读顺序。
- 页头只保留批次／比较组选择、刷新、新建、系统。实验结果／风控对比互斥显示，默认直接见结果。
- 概览固定五列：条件／赔率、观察状态、最低月ROI、最高月日结回撤、窗口净利。条件与赔率最多两行，其余单个短值；点击条件或行空白打开详情。
- 月度视图按月份展示ROI或日结回撤；风险视图最多六列。三个视图都使用现有observation响应，在本地切换。
- 来源、窗口范围、原始注额与共同输入提示集中在表上方；完整条件摘要放到“调整条件”抽屉，工具条只显示月数和收益门槛。
- 使用中性表格与少量状态色。只有明确达标、阶段达标或严重异常带状态文字；共同的known_skips不逐行重复。
- 桌面详情从右侧打开；手机全屏。设置、新建、系统、管理和续算共享同一遮罩，任意时刻只显示一个抽屉。
- 抽屉带dialog语义、标题关联、焦点进入与循环；关闭／Escape／遮罩按同一流程恢复焦点且不滚动背景。修改提交中禁止Escape关闭。
- 所有抽屉移到main之外，逐个携带lab-page样式作用域；背景inert与aria-hidden成对恢复。hidden状态明确CSS覆盖，不被布局display规则冲掉。
- 比较行详情使用独立batch上下文，金额／风控换算只取该子方案；保留原比较标签、筛选、视图、页码和滚动位置。
- 概览手机按两行重排，每行条件、状态和三个指标；只有月度视图允许自身横向滚动，不产生整页溢出。
- 验收使用真实WSGI/SQLite与jsdom，另注入真实CSS检查隐藏、作用域和DOM。未启动浏览器，不声称像素截图验收。
