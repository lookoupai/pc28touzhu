# 实施计划

## 摘要

串行完成领域与资金闭环、来源集成、交互与统计、回归与交付四个阶段。每阶段运行针对性测试后再进入下一阶段。

1. 领域与资金：规范集合、显式过滤、冻结子注、整组发送、逐注结算、组级倍投、命中与财务结果分离。
2. 来源：命名修正、opt-in 执行导出、表现统计、真实多注收益模拟；消费端兼容派生与去重。
3. 用户入口：订阅/自动触发/路由/风控/Bot/模板/记录说明，金额标识与全玩法的兼容行为。
4. 验证：领域、资金、旧功能、跨项目契约、浏览器；更新使用说明与发布准备文档。

模块分工按现有 domain、services、executor、ui 和来源 utils、services、static 组织。全部由主代理实施，禁止启动子代理。
