# 双组、杀组 UI 规范

## 摘要

- 复用现有组件、颜色、间距和响应式布局，不引入新视觉系统。
- 订阅展示六种双组和四个杀组方向；源派生仅两种双组，在提示中说明。
- 金额字段明确“每组合金额”，并说明双组乘 2、杀组乘 3；旧玩法金额语义不变。
- 默认全部保留原有玩法范围，新增玩法需要明确勾选；“选择全部”若包含新玩法应保存 selected 的全部键。
- 记录显示组级实际下注、总额与子注结果；覆盖命中和资金结果不同分别说明。

默认/hover/focus/active 复用 row-button、text-input、现有 checkbox/select 状态；disabled 用原禁用态，加载时保留原表单加载逻辑，错误原位显示且保留输入，空信号提示等待来源而不伪造预测。键盘、label、可见焦点沿用已有可访问结构。

移动/平板/桌面沿用已有栅格断点，组合长文本允许换行；长来源名继续截断并保留 title；超长列表使用既有分页；网络失败保留已输入金额与玩法。自动触发每种新玩法提供指标与具体方向，名称不混用“单组/双组”。
